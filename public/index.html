About

I’m a frontend and full-stack engineer. Most of my work now happens alongside AI agents.

So I build the tools I want for that: ways to see what an agent actually did, and to stay the one who decides what ships. Everything here is open source.

LEDRING

Status lights for AI agents, and a browser game about stopping one.

Play now Source ↗

How to play

  1. 01Press Start and give CX-417, an AI builder, an idea.
  2. 02Watch it build one web page in real time. It may cut corners.
  3. 03Approve, push back, or stop it. Reach one of 7 endings.

Under the hood

  • —Replays Claude Code and OpenTelemetry GenAI traces as one branch tree.
  • —Scores how far a run drifted from its instruction.
  • —CLI and GitHub Action. The game runs on the same engine.
  • —Free built-in AI, no key or sign-up. English and 中文.
